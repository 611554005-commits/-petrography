STEP-BY-STEP

Granoblastic 岩理判斷流程

在PPL/XPL薄片影像上，依序判斷是否屬於粒狀變晶結構（granoblastic texture），以及屬於哪一種次類型。點選圓圈標記已完成的步驟。

Foliated 與 porphyroblastic 都要先排除，才能確認是 granoblastic——這兩者不是granoblastic的變體，而是互斥的獨立分類。
TERMINOLOGY

脈（Vein）vs 樹枝狀（Dendrite）

一個描述空間構造，一個描述生長樣式——兩者不互斥，可以同時用於同一個特徵的不同層面。

Vein 構造/空間關係

岩石中一個明確、板狀（sheetlike）的結晶礦物體，由含礦質水溶液在既有裂隙內沉澱形成。

  • 重點：填滿一個既有的裂隙/破裂空間
  • 幾何上是線狀但實體、有明確邊界
  • 脈內部可以是任何礦物組成（石英脈、方解石脈、氧化錳脈皆可）
  • 通常與熱液循環（hydrothermal circulation）有關

Dendrite 生長樣式

元素或礦物質從一個起點向外遷移、分岔延伸所形成的樹狀構造，源自不同方向生長速率不均等。

  • 重點：分形（fractal）分岔的生長樣式本身
  • 常見於層面、節理面等「表面」，多為二維構造
  • 結晶度通常很低，顯示由膠體顆粒沉澱形成
  • 不一定發生在vein裡，也可以是單純的表面塗覆（surface coating）

如何描述同一個特徵

若黑色構造呈近垂直、連續、貫穿全片，先以 vein 描述整體幾何構造（裂隙填充的線狀體）；若脈內部或脈壁邊緣有分岔、羽毛狀細部紋理，再加上 dendritic texture within a vein 描述生長樣式。兩者是不同尺度、不同面向的描述，可以並存。

DESCRIPTIVE FRAMEWORK

顆粒狀特徵描述架構

依觀察層次由整體到細部：大小 → 形狀 → 邊界關係 → 整體分類。

1. 顆粒大小 Grain size

Fine / medium / coarse-grained。變質溫壓越高，再結晶後顆粒傾向越粗——可作為變質強度的間接指標。

2. 顆粒形狀 Crystal habit

Euhedral（自形）／Subhedral（半自形）／Anhedral（他形）；Equant（等軸狀）vs 拉長狀。Granoblastic結構中礦物通常anhedral到subhedral、等軸狀，不特別發展自己特有的晶形。

3. 顆粒邊界關係 Grain boundaries

Straight（平直）vs Sutured/curved（縫合狀/彎曲）；Triple junction（三連點，理想狀態下交角120°）；Interlocking mosaic（交鎖鑲嵌狀）。

4. 整體分類

Equigranular（等粒狀）vs Inequigranular（不等粒狀）。若有獨立大顆粒散布於細粒基質，改用 Porphyroblastic texture + Porphyroblast，與granoblastic互斥。

這套架構僅適用於PPL/XPL顯微照片——需要能看清個別顆粒邊界、消光關係與有無定向排列。巨觀掃描影像（如手標本或平台掃描）解析度不足，無法套用。
